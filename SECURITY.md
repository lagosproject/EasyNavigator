# 🔒 Security Policy

The Easy Navigator team takes the security and privacy of our users seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 18.0.x  | :white_check_mark: |
| < 18.0  | :x:                |

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or privacy leak in Easy Navigator, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the maintainers or use GitHub's private security advisory feature:
   - Security Contact: [Report a Security Advisory on GitHub](https://github.com/lagosproject/EasyNavigator/security/advisories/new)
3. Please include:
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - Android version and device tested on.
   - Assessment of impact.

## ⏱️ Response Timeline
- **Initial Acknowledgement:** Within 48 hours.
- **Triage and Verification:** Within 5 business days.
- **Fix Release:** As soon as feasible depending on severity.
- **Public Disclosure:** Coordinated after a fix has been published.
